# 6x6 Taxi Q-Learning Environment 🚖

Bu proje, özelleştirilmiş 6x6 ızgara ortamında bir taksinin yolcuyu alıp hedefe en kısa yoldan bırakmasını **Pekiştirmeli Öğrenme (Reinforcement Learning - Q-Learning)** kullanarak simüle eder.

## 📌 Özellikler
- **Custom Environment:** OpenAI Gym benzeri ancak özelleştirilmiş `TaxiEnv6x6` sınıfı.
- **Q-Learning:** Ajanın eğitimi için Q-Table tabanlı öğrenme algoritması.
- **Engeller:** Grid üzerinde belirli duvarlar ve kısıtlamalar.
- **Görselleştirme:** Eğitim sonrası ajanın performansını gösteren GIF çıktısı.
